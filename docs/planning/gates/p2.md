## Local evidence, 2026-09-11

- Reports accept a bounded time window and return the reviewer population, holdout exclusion
  policy and count, algorithm versions, candidate strategies, run filters, source snapshots,
  counts, and denominators.
- OpenRouter responses retain prompt, completion, and total token counts plus provider-reported
  cost. Calls with missing accounting remain distinguishable from known zero-cost cache hits.
- The final reviewed Python suite passed 622 tests at 87.71% coverage. The measurement path passed
  separately against a fresh PostgreSQL 16 database at Alembic head `f5c2d3e4a5b6`.

P2 closed with PR #70 because it is an implementation gate. It does not authorize collecting
family pilot data. P3-P5 must complete the participant and manager experience, P6 must close P1
and pass a synthetic end-to-end rehearsal, and only then may F1 use actual pilot perfumes. F1
retains the real baseline export with population, exclusions, strategy, algorithm version,
source snapshot, and denominators. OpenRouter token counts and provider-reported costs are
retained directly from its usage response; missing accounting remains explicit.
