## Local evidence, 2026-09-11

- Reports accept a bounded time window and return the reviewer population, holdout exclusion
  policy and count, algorithm versions, candidate strategies, run filters, source snapshots,
  counts, and denominators.
- OpenRouter responses retain prompt, completion, and total token counts plus provider-reported
  cost. Calls with missing accounting remain distinguishable from known zero-cost cache hits.
- The full Python 3.12 suite passed 610 tests at 87.76% coverage. The measurement path passed
  separately against a fresh PostgreSQL 16 database at Alembic head `f5c2d3e4a5b6`.

P2 cannot close formally before P1 closes because production measurements would otherwise be
collected on an unverified deployment. After release, run a declared pilot window, record
connectivity events, and retain a metrics export with population, exclusions, strategy, algorithm
version, source snapshot, and denominators. OpenRouter token counts and provider-reported costs
are retained directly from its usage response; missing accounting remains explicit.
