P5 delivers the controls needed to prepare and operate the pilot safely. Verification continues
to use synthetic or demo records.

| Work package | Required result | Retained evidence |
| :--- | :--- | :--- |
| P5.1 Program definition | Search exact versions, assign roles and repeats, validate, activate, and review the frozen definition | Manager end-to-end test |
| P5.2 Enrollment and sessions | Enroll evaluators, assign recorders, configure sessions, and see progress/missing work | Workflow test and screenshots |
| P5.3 Mapping and labels | Manager-only mapping and printable labels minimize disclosure | Authorization and print-layout evidence |
| P5.4 State transitions | Lock, reveal, and other consequential actions explain prerequisites and require appropriate confirmation | Transition tests |
| P5.5 Measurement reporting | Filter, view, and export metrics with population, exclusions, denominators, versions, strategy, and snapshot | Report/export fixture |
| P5.6 Operational events | Record connectivity failures/recoveries and view actionable service status without secrets | Failure/recovery test |
| P5.7 Authorization and disclosure | Every manager page, endpoint, cache, error, and export enforces role and disclosure policy; the matrix includes a participant requesting a cached manager response and records `no-store`, a policy-aware cache key, or an equivalent control; manager-to-manager partitioning is required only when responses differ by identity | Manager role/disclosure and cache-reuse matrix |

P5 closes when an authorized manager can prepare, operate, inspect, and close the workflow
without ad hoc API calls or direct database changes.

## Implementation progress, 2026-09-11

- Program setup searches the catalog and presents exact name, house, and concentration choices;
  repeat links use baseline names rather than copied membership IDs. The frozen-definition preview
  retains role, group, and identity-verification evidence.
- Enrollment uses named evaluators and explicit recorder usernames. The manager overview reports
  blotter completion, skin-plan state, skin completion, reveal blockers, and reveal state.
- Manager-only mappings include printable blind-code labels with human-readable exact-version
  details. Reveal is disabled until server-derived prerequisites pass and requires confirmation.
- Metric reporting accepts an evaluator and time window, displays population, exclusion policy,
  denominators, algorithm versions, candidate strategies, run filters, and snapshot count, and
  exports the complete contract as JSON evidence.
- Managers can record and review connectivity failures and manual recoveries. Operational status
  identifies affected evaluators and supplies recorder guidance without infrastructure details.
- Identity-dependent calibration, mapping, metrics, and operational reads send
  `Cache-Control: private, no-store` and `Vary: X-Authentik-Username`. The retained
  [manager disclosure matrix](../evidence/p5-manager-disclosure.md) covers cache reuse.
- The [synthetic manager-workspace capture](../evidence/p5-manager-workspace.png) retains the
  desktop definition, progress, blocker, mapping, label, report, and event layout without real
  family or perfume data.
- Ninety-three focused backend API tests and all 27 frontend tests pass. The production TypeScript build,
  ESLint, Prettier, Ruff, BasedPyright, changed-file security hooks, documentation checks, and
  strict MkDocs build pass.
