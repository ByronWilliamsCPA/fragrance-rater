**Status:** In progress; repository rehearsal kit prepared, target execution pending

**Owner:** Core maintainer

P6 is the hard boundary before actual perfume testing. No pilot fragrance is presented and no
family outcome is counted until P6.1-P6.6 all pass and P6.6 records a `go` decision.

| Work package | Required result | Retained evidence |
| :--- | :--- | :--- |
| P6.1 P1 closure | P1.1-P1.10 evidence passes against the release candidate and target topology | Completed P1 gate record |
| P6.2 Authenticated device matrix | Participant, recorder, and manager journeys pass through Authentik/Traefik on supported family devices | [Device/browser matrix](../evidence/p6-device-matrix.md) |
| P6.3 Synthetic rehearsal | Full setup-to-report workflow runs with unmistakably synthetic/demo samples and outcomes | [Rehearsal log and export manifest](../evidence/p6-synthetic-rehearsal.md) |
| P6.4 Quality gate | Accessibility, keyboard, responsive, performance, disclosure, and recovery checks pass on every critical page | [Consolidated quality report](../evidence/p6-quality-report.md) |
| P6.5 Operations rehearsal | Backup/restore, alerts, logs, secret ownership, and printable/manual outage procedure are exercised | [Operations drill record](../evidence/p6-operations-drill.md) |
| P6.6 Readiness decision | Participant/manager instructions and known limitations are reviewed; a decision is recorded and only `go` closes P6 | [Signed readiness record](../evidence/p6-readiness-decision.md) |

Any unmet P6.1-P6.6 result or a `no-go` decision blocks F1, including failures in workflow,
measurement, data integrity, authorization, blind disclosure, accessibility, responsive use,
performance, recovery, or operations. A failed gate returns work to the owning P sprint and
requires rerun evidence.

## Interim evidence, 2026-09-18: production deployment incident

An unplanned production deployment of `fragrance.williamshome.family` through Authentik/Traefik on
`docker-host` returned 502s, then went fully offline after a partial fix. Three chained defects
were found and fixed, each in its own PR:

- Wrong Docker build stage published (frontend served a non-production image), fixed by PR #100.
- A Trivy registry-scan CI bug blocked publishing the corrected image, fixed by PR #101.
- The container `HEALTHCHECK` used a hostname that resolved to an IPv6 address `wget` could not
  reach, so Docker never reported the container healthy even after the image fix landed, fixed by
  PR #102.

**Relevance to this gate:** this is a real exercise of the Authentik/Traefik target topology named
in P6.2, and it happened outside any planned rehearsal. It does not substitute for P6.2's device
matrix, and it does not touch P6.3-P6.6 at all (no synthetic data, no accessibility/keyboard/
responsive pass, no operations drill, no readiness decision). Recorded here so the gate's evidence
trail includes it rather than leaving a real deployment event undocumented.

**Reviewer:** Core maintainer. **Commit range:** PRs #100-102, merged 2026-09-18.
