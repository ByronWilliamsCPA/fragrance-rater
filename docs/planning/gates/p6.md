**Status:** Planned

**Owner:** Core maintainer

P6 is the hard boundary before actual perfume testing. No pilot fragrance is presented and no
family outcome is counted until every criterion below is reviewed.

| Work package | Required result | Retained evidence |
| :--- | :--- | :--- |
| P6.1 P1 closure | P1.1-P1.10 evidence passes against the release candidate and target topology | Completed P1 gate record |
| P6.2 Authenticated device matrix | Participant, recorder, and manager journeys pass through Authentik/Traefik on supported family devices | Device/browser matrix |
| P6.3 Synthetic rehearsal | Full setup-to-report workflow runs with unmistakably synthetic/demo samples and outcomes | Rehearsal log and redacted export |
| P6.4 Quality gate | Accessibility, keyboard, responsive, performance, disclosure, and recovery checks pass on every critical page | Consolidated quality report |
| P6.5 Operations rehearsal | Backup/restore, alerts, logs, secret ownership, and printable/manual outage procedure are exercised | Operations drill record |
| P6.6 Readiness decision | Participant/manager instructions and known limitations are reviewed and a go/no-go decision is recorded | Signed readiness record |

Any critical workflow, data-integrity, authorization, blind-disclosure, recovery, or mobile-use
failure blocks F1. A failed gate returns work to the owning P sprint and requires rerun evidence.
