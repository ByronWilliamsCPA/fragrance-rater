**Status:** Planned; blocked on P6

**Owners:** Product owner and core maintainer

F1 is the first use of actual pilot perfumes. It validates product usability and establishes
descriptive baselines; it is not evidence that a recommendation algorithm is accurate.

Before the first exposure, record the pilot dates, evaluators, exact physical samples, algorithm
and prompt versions, candidate strategy, source snapshot, exclusions, support procedure, and
stopping conditions in a private evidence location.

| Evidence | Required contents |
| :--- | :--- |
| Use and support log | UI-only task completion, abandonment, errors, help required, connectivity failures, and recoveries |
| Measurement export | Eligible impressions, explicit responses, interest, sampling, liking, wear/buy, unavailability, coverage, variety, and every denominator |
| Provenance record | Population, window, versions, strategy, filters, exclusions, source snapshot, and export hash |
| Pilot review | Usability findings separated from fragrance and algorithm outcomes; small-sample limits stated |
| Decision | Proceed to D1, revise a P3-P6 workflow, extend the declared pilot, or stop |

P6 evidence must remain valid throughout F1. A material deployment, disclosure, identity, or
measurement change pauses the pilot until the affected readiness checks are repeated.
